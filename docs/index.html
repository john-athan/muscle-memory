Muscle Memory

Figma, in a browser, behaving like it knows it is in one.

⇧⌘R

One key, two claimants

In Figma, ⇧⌘R is Paste to Replace. Press it meaning hard reload, with a slide selected, and Figma swaps that slide for whatever is on your clipboard.

The rule is not that the browser always wins. It is that the meaning you expect wins.

Why it cannot be broken

PRESS

You press the chord you have pressed for years.

CAPTURE

The listener on window gets it first, because it was there before Figma.

STOP

Propagation stops. Figma’s handler is never called.

DEFAULT

Nothing cancelled the default, so Chrome reloads.

What it will not promise

  • Moving a command means pressing the old key for you, with a keystroke Figma is allowed to ignore. The extension measures whether it worked and tells you.
  • Handing a chord back carries no such risk, which is why the destructive rule uses none.
  • The banner-hiding patterns will rot as Figma redesigns. They fail by doing nothing.
  • Some chords were never at risk. Those are listed too, rather than claimed as wins.
