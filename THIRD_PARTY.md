# Third-party material in muscle-memory

muscle-memory is MIT licensed and its source was written for this project. This
file records anything that came from elsewhere.

## Dependencies

The extension itself has none. It is plain HTML, CSS and JavaScript against the
Chrome extension APIs, ships no bundled library, and has no build step: the
folder that is committed is the folder Chrome loads.

The icon generator under `tools/icons` is a build-time tool and is not shipped.
It depends on:

- [`tiny-skia`](https://github.com/RazrFalcon/tiny-skia), MIT, path filling and
  stroking.
- [`image`](https://github.com/image-rs/image), MIT or Apache-2.0, used only for
  the Lanczos reduction and the PNG encoder.

Both are permissively licensed and compatible with MIT.

## Icons and screenshots

`icons/` is generated by `tools/icons` and is committed so that loading the
extension needs no Rust toolchain; CI fails if the two ever disagree. The
command glyph it draws is U+2318, a Unicode character, constructed from
primitives rather than copied from any typeface. Everything under `docs/` was
produced for this project.

## Provenance check

The provenance check, run as `oss provenance muscle-memory`, was originally
written for [carrier-pigeon](https://github.com/john-athan/carrier-pigeon), by
the same author, under the same licence. It now lives in the `oss-kit` fleet
tool.

## Figma

Not affiliated with Figma, Inc. "Figma" is their trademark and is used here
only to name the application this extension works with, which is nominative
use. No Figma source, asset or markup is copied into this repository. The
banner patterns in `src/selectors.js` match against wording that appears in
Figma's interface, in the way an ad blocker matches a page it did not write.
